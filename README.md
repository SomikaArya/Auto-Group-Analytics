# 🚗 Auto Group Analytics Dashboard

## 📌 Project Overview

The **Auto Group Analytics Dashboard** is an interactive Business Intelligence project developed using **IBM Cognos Analytics** to analyze automotive sales performance, dealership operations, customer sentiment, and vehicle recalls. By integrating multiple datasets into a single dashboard, the project provides meaningful insights that support data-driven decision-making for automotive businesses.

The dashboard is divided into two primary sections:

* **Sales Dashboard** – Focused on profitability, sales volume, and dealer performance.
* **Service Dashboard** – Focused on recalls, customer sentiment, and service-related analytics.

## 🎯 Objectives

* Analyze overall sales and profitability across dealerships.
* Compare vehicle sales by model.
* Monitor dealership performance using KPIs.
* Evaluate customer sentiment from feedback data.
* Track recall trends by vehicle model and affected system.
* Provide an executive-level dashboard for business monitoring.

## 📂 Dataset Information

The dashboard was created by combining multiple files from the **Automotive_Industry** dataset:

* **AU_Daily_Sales.xlsx** – Daily sales transactions, weather conditions, and dealer information.
* **AU_Dealers.xlsx** – Dealer details including location and contact information.
* **AU_Car_Models.xlsx** – Mapping between Car IDs and vehicle models.
* **AU_Car_Recalls.xlsx** – Vehicle recall records with affected systems and recall units.
* **AU_Sentiment.csv** – Customer sentiment data categorized as Positive, Neutral, or Negative.

These datasets were connected using common fields such as **Dealer ID**, **Car ID**, **Model**, and **Date** to create a unified analytical dashboard.
